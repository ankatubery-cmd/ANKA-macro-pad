# ANKAtuber

ANKAtuber, içerik üreticisi **ANKAtuber** için geliştirilen Android uygulamasıdır.

Uygulama; yayın sırasında uzun sürecek işleri bir kısayol ile yapmanızı sağlayan bir android uygulamasıdır.

## Hakkında

ANKAtuber uygulaması, topluluk ile içerik üreticisi arasındaki bağlantıyı güçlendirmek için geliştirilmektedir.

Uygulama üzerinden yayın ve içeriklere erişebilir, uygulamaya özel özellikleri kullanabilir ve gelecekte eklenecek topluluk özelliklerinden yararlanabilirsiniz.

## Özellikler

- Ana ekran widget'ları
- Android cihazlara uyumlu arayüz
- Uzantı desteği için geliştirilebilir yapı

## Ekran Görüntüleri

> Ekran görüntüleri yakında eklenecek.

## Widget'lar

ANKAtuber, Android ana ekranında kullanılabilen widget'ları destekler.

Widget sistemi sayesinde uygulamayı açmadan belirli bilgilere hızlıca erişilebilir.

Mevcut widget özellikleri:

uzantılar neyi gösterirse o

Widget sistemi ilerleyen sürümlerde daha fazla özellik destekleyecek şekilde geliştirilecektir.

## Kurulum

1. GitHub Releases üzerinden uygun APK dosyasını indirin.
2. APK'yı açarak kurulumu başlatın.
4. server arşivini bilgisayarınıza kurun
   gerekli kurulum talimatları arşiv içindedir
5. tebrikler artık kısayol oluşturabilir ya da uzantı yazabilirsiniz   

> Geliştirme sürümlerinde APK'nın kurulumu sırasında cihazınız ek izin isteyebilir.

## Kullanım

Uygulamayı açtıktan sonra ana ekrandan mevcut özelliklere erişebilirsiniz.

## Katkıda Bulunma

ANKAtuber'ın geliştirilmesine katkıda bulunmak isteyen geliştiriciler GitHub üzerinden projeyi inceleyebilir, hata bildirebilir ve geliştirme önerileri sunabilir.

Kod değişiklikleri göndermeden önce mevcut proje yapısına ve kodlama düzenine uyulması önerilir.
